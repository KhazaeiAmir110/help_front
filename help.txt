1) فرق react , angular :
در react سعی براین شده تا از html در js استفاده و bundle شود ولی در angular برعکس است.

2) با استفاده از ۴ ابزار میتوان کتابخانه هایی مانند react را نصب و مدیریت کرد.
 التبه ابزار create react مخصوص react است.
 که در فایل tools از هر ۴ ابزار استفاده شده است.

 3) Component :
 از نظر react کامپوننت ها یکسری کلاس یا تابع هستند که میتوانند یک مقدار ورودی بیگیرند و یک element برگردانند.
 در react به ۳ دسته قابل تقسیم بندی هستند :
a) Built-in Component
b) Class Component
c) Function Component

+ چرخه حیات component :
1) mounting => زمان تولد
2) updating => تغییر قسمت یا کل
3) unmounting => زمان مرگ


4) Hooks

a) useState : دیتای برنامه ما است که میتواند تغییر کند

b) useEffect :
1) امکان مدیریت رفتار یا اعمالی که باعث تاثیر خارجی در تابع میشود
2) امکان مدیریت چرخه حیات کامپوننت

c) useContext :
یک روش برای انتقال داده بین کامپوننت های مختلف
